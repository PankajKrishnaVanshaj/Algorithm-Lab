How to Reverse a Linked List: The Pointer Change That Reverses the Chain

Reversing a singly linked list changes the direction of its next pointers. The iterative method uses three references—previous, current and next—so it can reverse the links without losing access to the remaining nodes.

An educational guide from PANKRI · Published November 3, 2026

How a singly linked list is connected

A singly linked list is a sequence of nodes. Each node stores a value and a reference to the next node. The head reference points to the first node, and the last node points to null. Unlike an array, nodes do not need to occupy adjacent memory locations.

To reverse the list, the program changes every next reference so it points to the previous node. The old tail becomes the new head.

The three-pointer idea

Use three references:

  • previous starts as null and trails behind the current node.
  • current starts at the head and identifies the node being processed.
  • next temporarily saves the next node before the current link is changed.

At each iteration, save current.next, point current.next to previous, then move previous and current one node forward. Saving next first is essential: overwriting the pointer before saving it would lose the rest of the chain.

Reverse A → B → C → null

  1. Start with previous = null and current = A.
  2. Save next = B. Change A.next to null. Move previous to A and current to B.
  3. Save next = C. Change B.next to A. Move previous to B and current to C.
  4. Save next = null. Change C.next to B. Move previous to C and current to null.
  5. The loop ends. Set the head to previous, which is C.

The final chain is C → B → A → null. No node was copied; only the links were reversed.

JavaScript implementation

function reverseList(head) {
  let previous = null;
  let current = head;

  while (current !== null) {
    const next = current.next; // Save the rest of the list
    current.next = previous;   // Reverse this link
    previous = current;        // Advance previous
    current = next;            // Advance current
  }

  return previous; // New head
}

This assumes each node has a next property and that the list is acyclic. The function returns the new head; callers must store that returned reference.

Time and space complexity

The algorithm visits each node once, so its time complexity is O(n). It uses a fixed number of extra references regardless of list size, so its auxiliary space complexity is O(1). A recursive version is possible, but it uses call-stack space proportional to the list length.

Important edge cases

  • Empty list: null is returned.
  • Single-node list: that node remains the head and its next reference remains null.
  • Two-node list: the second node becomes the head and points to the first.
  • Cycles: this standard algorithm assumes an acyclic list; a cycle can cause an endless loop.

Frequently asked questions

Does reversing a linked list need extra memory?

The iterative in-place algorithm uses O(1) auxiliary space because it only stores a fixed number of node references.

Why save next before changing current.next?

Changing current.next destroys the only forward reference from the current node. Saving it first ensures the remaining chain is not lost.

What does the function return?

It returns the new head, which was the old tail. The caller should update its head reference to this returned node.
