What is a data structure?

A data structure is a way to organize and manage data so operations can be performed efficiently. The right structure depends on how data is accessed, inserted, removed and searched. This lab focuses on three foundational linear structures.

Stack: Last In, First Out

A stack follows LIFO order: the most recently added item is the first one removed. Push adds an item to the top, pop removes the top item, and peek reads the top without removing it. These operations are O(1) in a typical array-backed or linked implementation. Stacks are used in function calls, undo systems, parsing and depth-first search.

Queue: First In, First Out

A queue follows FIFO order: the earliest inserted item is removed first. Enqueue adds an item at the rear, while dequeue removes an item from the front. A well-designed circular-buffer or linked implementation can perform both in O(1). Queues are used in task scheduling, buffering, breadth-first search and request processing.

Singly linked list

A singly linked list contains nodes. Each node stores a value and a reference to the next node. Inserting at the head is O(1). Searching for a value is O(n). Appending is O(n) without a tail reference and can be O(1) when a tail reference is maintained. Deleting a value usually requires finding its previous node first.

Frequently asked questions

What is the difference between a stack and a queue?

A stack removes the newest item first (LIFO), while a queue removes the oldest item first (FIFO).

Are stack push and pop O(1)?

They are O(1) in common implementations when the stack has available capacity or uses a linked representation. Dynamic-array resizing can occasionally make an individual push more expensive, though append is amortized O(1).

Is a linked list faster than an array?

Neither is universally faster. Linked lists support O(1) insertion at a known node or at the head, but indexed access is O(n). Arrays provide O(1) indexed access and often better cache locality.
