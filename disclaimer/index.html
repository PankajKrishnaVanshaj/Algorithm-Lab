Educational information only

The articles, explanations, code snippets and interactive visualizations on this website are provided for general educational and informational purposes. They are not a guarantee that a particular algorithm or implementation is appropriate for your project.

Operation counts are not runtime benchmarks

The counters shown in Algorithm Lab represent selected operations recorded by the visualizer. They do not measure standardized CPU time, memory bandwidth, browser performance or energy use. Different implementations may count operations differently. For fair performance comparisons, use a controlled benchmark with documented hardware, software, input distributions and measurement methods.

Complexity analysis has assumptions

Big-O summaries describe how resource requirements grow under stated assumptions. Actual behavior can depend on input size and distribution, implementation, data structures, compiler or runtime, memory constraints and hardware. Best-case, average-case and worst-case results should not be treated as interchangeable.

Check code before relying on it
