What is a graph?

A graph consists of vertices (also called nodes) and edges that connect pairs of vertices. Edges may be directed or undirected, and they may carry weights such as distance, cost or time. Graphs are used to model road networks, computer networks, dependencies, social connections and state transitions.

Breadth-First Search (BFS)

BFS explores a graph in layers. It starts at a source node, visits its immediate neighbors, then visits the next layer. A queue controls the order of exploration. In an unweighted graph, BFS can find a path with the fewest edges from the source to reachable nodes. Its time complexity is O(V + E) when adjacency lists are used.

Depth-First Search (DFS)

DFS follows one branch as far as it can before backtracking. It can be implemented with recursion or an explicit stack. DFS is useful for reachability, connected components, cycle detection and topological sorting in directed acyclic graphs. With adjacency lists, its time complexity is O(V + E). DFS does not generally find a shortest path.

Dijkstra’s shortest-path algorithm

Dijkstra’s algorithm computes shortest-path distances from a source in a graph with non-negative edge weights. It repeatedly selects the unsettled node with the smallest known tentative distance and relaxes its outgoing edges. A common implementation with a priority queue runs in O((V + E) log V), while simpler implementations can take O(V²). Dijkstra is not valid for graphs containing negative-weight edges.

Representing a graph in memory

An adjacency list stores, for each vertex, the vertices or edges directly connected to it. It uses space proportional to V + E and is a natural fit for sparse graphs, where the number of edges is far below V². An adjacency matrix stores a table with one cell for each possible pair of vertices. It uses O(V²) space but can test whether a particular edge exists in constant time.

Choose a representation based on the operations you need. Traversals usually benefit from adjacency lists because they can iterate over the neighbors that actually exist. A dense graph or an application that repeatedly checks arbitrary edges may make a matrix attractive. Directed graphs also require care: an edge from A to B does not automatically imply an edge from B to A.

BFS and DFS answer different questions

Breadth-First Search uses a queue. Once it visits every vertex one edge away from the source, it moves to vertices two edges away, then three, and so on. In an unweighted graph, this layer order means the first discovered path to a vertex uses the fewest edges. It does not minimize a weighted cost when edge weights differ.

Depth-First Search uses recursion or an explicit stack to explore one branch deeply before backtracking. It is useful for discovering reachability, connected components, cycle structure and topological order in a directed acyclic graph. The first path found by DFS is not guaranteed to have the fewest edges. With adjacency lists, both traversals take O(V + E) time because each vertex and edge is processed a bounded number of times.

Where Dijkstra fits—and where it does not

Dijkstra adds edge weights to the path problem. It repeatedly settles the reachable unsettled vertex with the smallest tentative distance, then relaxes outgoing edges. Non-negative edge weights are essential to the greedy step: once a vertex is settled, a later route cannot improve it by passing through a vertex whose tentative distance is already no smaller.

If edge costs can be negative, that argument fails. Bellman–Ford is a common alternative for graphs with negative edges and can also detect a reachable negative cycle. If all you need is the fewest edges in an unweighted graph, BFS is simpler. If you need a minimum spanning tree rather than shortest paths from a source, Prim's or Kruskal's algorithm addresses a different problem.

How to learn from a graph trace

Keep the graph fixed and change only the starting vertex or selected algorithm. For BFS, watch the queue-like frontier and group nodes by distance in edges. For DFS, note how backtracking occurs when a branch has no unvisited neighbors. For Dijkstra, track the current tentative distance and predecessor whenever relaxation improves a route. If two paths have equal total weight, either may be a valid shortest path, so the exact predecessor tree can depend on tie-breaking order.

For reference, Princeton's Algorithms, Part 4.1: Undirected Graphs explains graph representations, DFS and BFS, while its Shortest Paths chapter covers weighted paths and Dijkstra's assumptions.

Frequently asked questions

Does BFS always find the shortest path?

BFS finds a path with the fewest edges in an unweighted graph. If edges have different costs, BFS does not generally minimize total weight.

Can Dijkstra handle negative edge weights?

No. Dijkstra’s correctness requires non-negative edge weights. Bellman–Ford is one alternative when negative weights are present and negative cycles must be detected.

What is the difference between BFS and DFS?

BFS explores level by level using a queue. DFS explores deeply along a branch using a stack or recursion. Their traversal order and use cases differ.
