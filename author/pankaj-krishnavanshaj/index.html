Profile

Pankaj KrishnaVanshaj is the maintainer of PANKRI Algorithm Lab. He holds a Bachelor of Computer Applications (BCA) degree from Chhatrapati Shahu Ji Maharaj University, Kanpur, and works as a web developer with the MERN stack, Next.js and NestJS.

Focus of the project

Algorithm Lab is an independent learning project that explains selected computer science topics through practical examples and browser-based visualizations. Its current learning paths cover sorting, searching, graph traversal, shortest paths, stacks, queues, linked lists, algorithmic complexity, Bloom Filters and JavaScript number precision.

How to interpret the examples

Examples are written for learning and are intentionally small enough to follow. A visualizer's operation counters describe the operations recorded by its own implementation; they are not universal instruction counts or controlled performance benchmarks. Some demonstrations, such as the small Bloom Filter model, use simplified educational logic and are not intended as production or security libraries.
